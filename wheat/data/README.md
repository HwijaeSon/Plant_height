# Wheat data provenance

- `align_height_env_same_length.csv`: processed height/environment table from
  the companion repository to Shao et al. (2026).
- `kinship_matrix_astle.csv`: genotype kinship matrix from the same workflow.

The model reported in the manuscript uses only one-hot genotype encoding, but
the kinship file is retained so the alternative encoding remains reproducible.
Before redistributing these files publicly, verify their terms against the
original ETH dataset and companion repository.
