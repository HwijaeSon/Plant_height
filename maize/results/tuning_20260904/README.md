# 옥수수 Latent Neural ODE 튜닝

**완료:** 실제 탐색·평가 180분, 67개 설정·95회 실행, 실패 0회.
3개 시드를 모두 완료한 14개 설정 중 검증 평균으로 `l160`을 선택했다.
시험 rRMSE는 기존 25.84±4.26%에서 **18.40±1.42%**로 감소했다.

[최종 비교표·그림·체크포인트](final/README.md) · [비교 CSV](final/comparison.csv) · [검증 기록](final/validation.json)

아래는 실행 전에 정한 계획이다.

요청 범위: 우리 모델만, 약 3–4시간. GPU 0·1·2번에서 후보를 독립 실행한다.
실행 예산은 200분이며, 프로토콜의 종료 시각은 한국 시간 2026-09-05 02:03경이다.
준비 시간을 포함하면 약 3시간 30분 계획이다.

## 고정 조건

- 학습 2018–2019, 검증 2020, 시험 2021.
- 기존 402개 유전자형, 1,533개 학습 시험구와 관측 마스크를 유지한다.
- 높이·기온 정규화는 기존 학습 연도 통계만 사용한다.
- 후보별 checkpoint는 매 10 epoch의 검증 RMSE 최솟값으로 선택한다.
- 후보 실행 중 시험 점수를 계산하거나 기록하지 않는다.
- 최종 설정은 세 시드 검증 RMSE 평균으로 확정하고, 그 세 checkpoint만 시험 평가한다.
- baseline 및 기존 모델 구현·완료 결과는 보존한다.

## 탐색 단계

| 단계 | 시간 배분 | 실행 내용 |
|---|---:|---|
| 폭넓은 탐색 | 약 90분 | 학습률·물리 손실·정규화·모델 크기·시간 표현, 시드 1, 1,500 epoch |
| 시드 재검증 | 약 50분 | 검증 상위 8개 설정에 시드 2·3 추가 |
| 학습 길이 확인 | 약 45분 | 세 시드 검증 상위 3개 설정을 3,000/4,500 epoch로 다시 실행 |
| 최종 평가 | 약 15분 | 설정 고정, 체크포인트 검증, 시험 평가, 표·그림 작성 |

각 단계는 남은 시간과 측정한 실행 속도를 고려해 새 작업을 배정한다.
시간 부족으로 모든 시드를 완료하지 못한 후보는 최종 선택에서 제외한다.
빨리 끝나는 단계의 여유 시간은 뒤 단계에서 사용할 수 있다.

## 파일

- `protocol.json`: 사전에 고정한 분할, 선택 규칙, 범위, GPU UUID, 코드·데이터 SHA-256.
- `configs/`: 후보별 hyperparameter 설정.
- `status.json`: 현재 단계, 진행률, 검증 기준 상위 후보.
- `trials/`: 학습 로그, validation-only 이력, 체크포인트, 결과.
- `completed.json`, `failures.json`, `skipped.json`: 완료·오류·예산상 제외 기록.
- `screen_selection.json`, `replicate_selection.json`: 단계별 후보 선정 기록.
- `selected.json`: 시험 평가 전에 고정하는 최종 설정과 체크포인트 SHA-256.
- `final/README.md`: 완료 시 튜닝 전후 비교표와 그림.

기존 설정을 새 실행기로 재현한 첫 후보 `c000`의 시드 1 검증 RMSE는
111.152559, 선택 epoch는 30으로 기존 결과와 일치했다.

```bash
OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 .venv/bin/python -u maize/code/tune_search.py \
  --output maize/results/tuning_20260904 --gpus 0 1 2 --minutes 200
```

이미 초기화한 폴더에는 검색을 다시 시작하지 않는다. 재실행은 새 `--output` 경로를 사용한다.
