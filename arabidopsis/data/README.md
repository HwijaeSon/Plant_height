# Arabidopsis data provenance

`raw/12870_2024_5394_MOESM5_ESM.xlsx` is the supplementary workbook from
Ebrahimi Naghani et al. (2024), DOI: 10.1186/s12870-024-05394-w.
`processed/stem_length_long.csv` is the 720-row tidy table generated by
`../code/prepare_data.py` from the `stem length_nAT` and `stem length_hAT`
sheets. Length is stored in both centimetres and metres.

Before public redistribution, confirm the supplementary material's licensing
terms. The workbook can instead be omitted and restored with
`../code/download_data.sh`.
